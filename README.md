# Photo Sequencer

Lay out photos on book spreads, in inches.

## Run locally

```bash
nvm use        # Node 24 (needs ≥ 20.19)
npm install
npm run dev    # → http://localhost:5173
```

## Build

```bash
npm run build  # → dist/
```

## Shortcuts

| Action       | Mac   | Windows |
| ------------ | ----- | ------- |
| Add photos   | ⌘O    | Ctrl+O  |
| Preview      | ⌘P    | Ctrl+P  |
| Settings     | ⌘,    | Ctrl+,  |
| Undo         | ⌘Z    | Ctrl+Z  |
| Redo         | ⇧⌘Z   | Ctrl+Y  |

Hold ⌘ / Ctrl to see them on screen.
