Support

Sequence, on the web and for Mac

Questions, bug reports, or ideas? Email hi@sequence.photos. It helps to say whether you're using the website or the Mac app, and which version (in the About pane).

Where's my work saved?

On the website, in your browser's storage on this device. Use File → Export project to keep a copy, or to move it to another browser or computer. In the Mac app, in the project file you save (File → Save).

What does it need?

The website works in current versions of Chrome, Edge, Safari, and Firefox, and keeps working offline once it's loaded. The Mac app needs macOS 13 or later.
